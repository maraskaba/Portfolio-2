Monitoreo y conciliación de horas presupuestadas

Diseño y validación de un dashboard para monitorear horas presupuestadas, horas consumidas y desvíos financieros sin depender de análisis manuales.

Cliente Blink.la
Año 2024
Scope Diseño UX / Diseño UI / Entrevistas exploratorias

Contexto

Content Studio es una suite de herramientas diseñada para automatizar, controlar y hacer seguimiento de producciones audiovisuales. El equipo de Finanzas necesitaba mayor visibilidad sobre uno de los datos clave de los proyectos. El análisis de datos se hacía con el uso de herramientas externas.

Problema

El análisis financiero dependía de pasos manuales y herramientas externas. Las horas se cargaban en el módulo de time tracking, pasaban por aprobaciones y luego debían reconciliarse contra el budget correspondiente.

Para generar visibilidad, el equipo descargaba los datos en CSV, los subía a un dashboard externo y revisaba los desvíos en reuniones semanales.

Esto generaba tres problemas principales:

Información fragmentada

La información necesaria para entender el estado financiero de una producción estaba dispersa entre distintos módulos, planillas y dashboards externos.

Falta de visibilidad temprana

Los desvíos entre horas cargadas y presupuesto se detectaban tarde, recién en la revisión semanal del equipo de Finanzas.

Proceso operativo manual

El equipo dependía de exportaciones, cruces de datos y reuniones para entender qué producciones estaban dentro o fuera de presupuesto.

Objetivos

  • Integrar el dashboard financiero dentro de Content Studio.
  • Habilitar alertas tempranas mediante indicadores visuales y notificaciones.
  • Simplificar la conciliación de las horas pendientes.
  • Mejorar la eficiencia del equipo de Finanzas en la detección y seguimiento de problemas.

Abordaje de diseño

El análisis mostró que el problema no era solamente visualizar datos, sino conectar distintas partes del flujo: carga de horas, aprobación, presupuesto, reconciliación y seguimiento financiero.

Solución

Diseñamos un dashboard dentro de Content Studio para comparar horas presupuestadas, horas consumidas y costos asociados a cada producción.

Flujo de conciliación de horas

Además del dashboard, diseñamos una vista de conciliación para revisar horas, costos y estados asociados a una producción.

Esta vista permitía pasar del monitoreo general a la revisión operativa, diferenciando información pendiente, aprobada o reconciliada.

Validación con stakeholders

Validamos la propuesta con Finanzas y Operaciones para revisar si el flujo cubría las principales acciones del proceso:

  • Identificar horas sin reconciliar.
  • Seleccionar tareas pendientes.
  • Asignar cada tarea al budget item correspondiente.
  • Actualizar reconciliaciones.
  • Analizar el estado general desde el dashboard.

La revisión permitió ajustar la jerarquía de información, reforzar estados e indicadores visuales, y conectar mejor el dashboard con la operación diaria.

Resultados

Flujo integrado

Se eliminó la necesidad de exportaciones manuales a herramientas externas.

Detección temprana de desvíos

Se identifican rápidamente sobreusos o subusos de tiempo y desajustes presupuestarios.

Seguimiento estructurado

Los problemas se revisan de forma periódica en reuniones semanales.

Simplificación de aprobación de costos

Se facilitó la detección y aprobación masiva de costos pendientes.

El equipo financiero pasó de revisar información fragmentada en herramientas externas a monitorear y operar desvíos desde un flujo integrado dentro de Content Studio.
